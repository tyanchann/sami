# ASSETS_LICENSES — лицензии на ресурсы

Всё, что использует игра, лежит **локально в этой папке**. Внешних CDN, шрифтов
по ссылке, картинок-хотлинков и сторонних JS-библиотек нет. Ниже — происхождение
и лицензия каждого ресурса.

---

## 1. Шрифты

| Файл | Шрифт | Лицензия | Источник |
|---|---|---|---|
| `assets/fonts/Inter-latin-400_700.woff2` | Inter (латиница, вариативный 400–700) | **SIL Open Font License 1.1** | Google Fonts |
| `assets/fonts/Inter-cyrillic-400_700.woff2` | Inter (кириллица, вариативный 400–700) | **SIL Open Font License 1.1** | Google Fonts |
| `assets/fonts/Manrope-latin-600_800.woff2` | Manrope (латиница, вариативный 600–800) | **SIL Open Font License 1.1** | Google Fonts |
| `assets/fonts/Manrope-cyrillic-600_800.woff2` | Manrope (кириллица, вариативный 600–800) | **SIL Open Font License 1.1** | Google Fonts |
| `assets/fonts/fonts.css` | правила `@font-face` для перечисленных файлов | — | написано для проекта |

Inter — основной шрифт: вопросы, варианты ответов, кнопки, инструкции, подписи,
финальные строки и письмо в открытке. Manrope — только заголовки и короткие
акцентные строки. Пиксельные шрифты (Silkscreen, Pixelify Sans) из проекта удалены.

SIL OFL 1.1 разрешает использование, встраивание и распространение шрифта вместе
с документом/приложением, в том числе коммерческим, при сохранении уведомления
об авторстве. Шрифты не продаются отдельно и не модифицировались (только
перекодированы в woff2 средствами Google Fonts). Текст лицензии:
<https://openfontlicense.org/open-font-license-official-text/>

## 2. Музыка

| Файл | Название | Автор | Лицензия | Источник |
|---|---|---|---|---|
| `assets/music/daisy.mp3` | «Daisy» | **Kistol** | **CC0 1.0 Universal** (общественное достояние) | OpenGameArt — <https://opengameart.org/content/daisy> |

Трек звучит в финале начиная со сцены с фотографиями: 128 секунд, зациклен,
громкость ~0.34, плавное затухание при переходе к открытке. Стартует только
после первого касания (политика браузеров), отключается кнопкой звука
в HUD; состояние mute сохраняется между сессиями.

CC0 не требует указания автора, но автор указан — из уважения к работе Kistol.

---

## 3. Звуковые эффекты

**Файлов нет.** Все SFX (верный/неверный ответ, трещины, разбивающееся сердце,
выстрел, попадание, прыжок, подбор фрагмента, переворот карточки, совпадение,
сборка сердца, пульс, финальный аккорд, салют) **синтезируются на лету** через
Web Audio API в `js/core/audio.js` — осцилляторы, шум, огибающие.
Лицензий не требуется, ничего не скачивается.

## 5. Фотографии

**Фотографий в поставке нет.** Игра ждёт три файла в `assets/photos/`
(`image.png`, `image1.png`, `image2.png`) — их владелец проекта кладёт сам.
Права на эти снимки остаются у их владельца; игра только отображает их локально,
никуда не отправляет и не загружает на сервер (никакой аналитики и сетевых
запросов, кроме самой страницы).

Пока фото нет, показываются нарисованные заглушки — чужих изображений
в проекте не используется.

---

## 6. Код

HTML, CSS и JavaScript написаны для этого проекта. Сторонних библиотек нет:
ни React, ни Three.js, ни jQuery, ни шрифтовых/анимационных пакетов.
Внешних запросов при работе игры — ноль (проверено в QA: единственный хост
в логе — локальный сервер).
